# Manga Parser

Десктопное приложение, которое готовит мангу, скачанную с InkStory, к сборке
в [Kindle Comic Converter](https://github.com/ciromattia/kcc).

На входе — архив со всеми главами или папка, в которой лежат их `.zip`-файлы,
и необязательная обложка. На выходе — плоская папка со сквозной нумерацией
страниц (`00001.jpg`, `00002.png`, …), которую KCC принимает как есть.

## Как это работает

1. Если источник — архив, он распаковывается во временную папку.
2. Все `.zip` внутри собираются и сортируются «естественно»: глава 10 идёт
   после главы 9, а не после первой.
3. Обложка, если выбрана, копируется первой страницей — главы сдвигаются на
   одну. Исходный файл остаётся на месте.
4. Каждая глава распаковывается по очереди, картинки (`jpg`, `jpeg`, `png`,
   `gif`, `webp`) переносятся в результат со сквозным номером.
5. Повреждённые архивы пропускаются с предупреждением в журнале, сборка
   продолжается.

Существующая папка результата очищается перед сборкой, поэтому её нельзя
назвать так же, как папку-источник — приложение это проверяет и откажется
работать.

## Структура

| Каталог     | Ответственность                                              |
| ----------- | ------------------------------------------------------------ |
| `core/`     | Бизнес-логика: поиск глав, сортировка, распаковка, нумерация. Ничего не знает про UI. |
| `src-tauri/`| Адаптер Tauri: команды, единственная активная сборка, проброс событий ядра в окно. |
| `src/`      | Интерфейс: Material Design 3 на своих токенах, светлая и тёмная темы.  |

Связь между слоями — порт `Reporter` из `core`: ядро сообщает о ходе работы и
спрашивает про отмену, не зная, кто его вызвал. В тестах его роль играет `()`.

## Разработка

```bash
npm install
npm run tauri dev
```

Сборка под текущую систему:

```bash
npm run tauri build
```

## Релизы

Tauri не умеет собирать чужую платформу: каждый установщик собирается на своей
ОС. Этим занимается workflow `.github/workflows/release.yml` — он поднимает три
раннера и складывает результат в черновик релиза:

| Платформа   | Раннер          | Артефакт        |
| ----------- | --------------- | --------------- |
| macOS (M-серия) | `macos-latest`  | `.dmg`, `.app`  |
| Linux x86_64    | `ubuntu-22.04`  | `.AppImage`     |
| Windows x86_64  | `windows-latest`| `.msi`, `.exe`  |

Запускается пушем тега или вручную из вкладки Actions:

```bash
git tag v1.0.0 && git push origin v1.0.0
```

Сборки не подписаны, поэтому macOS при первом запуске потребует «Открыть» через
контекстное меню, а Windows покажет предупреждение SmartScreen.

Иконка приложения и знак в шапке — один и тот же файл `public/app-icon.svg`.
После правки нужно перегенерировать наборы для сборщика:

```bash
rsvg-convert -w 1024 -h 1024 public/app-icon.svg -o app-icon.png
npx tauri icon app-icon.png && rm app-icon.png
```

Тесты и линтеры:

```bash
cargo test --workspace && cargo clippy --workspace --all-targets
```
